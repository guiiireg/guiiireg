## About

I'm a software development student based in Nantes, passionate about building full-stack applications, designing robust software architectures, and understanding systems from the database layer to the user interface.

I mainly work with **Java (Spring Boot), PHP 8+ (Laravel), TypeScript / JavaScript (React & Next.js), C# (.NET), Dart (Flutter), and Angular**. I place a strong emphasis on clean code, REST & GraphQL API design, relational data modeling, web standards / accessibility (WAI-ARIA), containerization, and Linux-based workflows.

I use **Arch Linux** as my main development environment and prefer learning by building practical, production-ready projects.

### Exon

<div align="center">

[![Exon](https://img.shields.io/badge/View%20Project-Exon-181717?style=for-the-badge&logo=github)](https://github.com/Exoncode-stream/Exon)

</div>

Official web platform and developer community hub for sharing software engineering experiments, accessible design, and learning resources.

`Next.js 16` · `React 19` · `TypeScript` · `Tailwind CSS v4` · `Semantic HTML5` · `WAI-ARIA`

* **100% Strict Semantic HTML5**: Built without generic container elements (`div`/`span`) for a native, clean accessibility tree.
* **Native Accessibility (WAI-ARIA)**: Full landmark navigation, direct section bindings, and keyboard/screen reader compatibility.
* **Optimized Rendering**: Static Site Generation (SSG) with Next.js App Router for instant load speeds and optimal SEO.
* **Modern Design System**: Dark-first aesthetic with Tailwind CSS v4 and fluid CSS micro-interactions with reduced-motion support.
* **Technical Deep-Dive Content**: In-depth articles on web standards, front-end architecture, and engineering principles.

### Code Quest

<div align="center">

[![Code Quest](https://img.shields.io/badge/View%20Project-Code%20Quest-181717?style=for-the-badge&logo=github)](https://github.com/guiiireg/code-quest)

</div>

Full-stack gamified coding platform inspired by RPGs, where developers solve programming quests to earn XP and level up.

`Java 21` · `Spring Boot 4` · `Angular 19` · `RxJS` · `PostgreSQL 16` · `Hibernate / JPA` · `Docker Compose` · `JWT`

* **Decoupled Architecture**: RESTful API backend built with Java 21 and Spring Boot.
* **Stateless Security**: Route protection and user authentication via Spring Security with JWT tokens.
* **Data Persistence**: Relational database modeling with PostgreSQL 16, managed through Spring Data JPA & Hibernate ORM.
* **Gamification Engine**: Dynamic user code validation and RPG progression logic (XP, worlds, quest tiers).
* **Reactive Frontend**: Client interface built with Angular 19, Angular Material, and RxJS state management.
* **Containerized Environment**: PostgreSQL service managed via Docker Compose with automated unit & integration test suites (JUnit 5, Jasmine / Karma).

### CityDrive Manager

<div align="center">

[![CityDrive Manager](https://img.shields.io/badge/View%20Project-CityDrive%20Manager-181717?style=for-the-badge&logo=github)](https://github.com/guiiireg/CityDrive-Manager)

</div>

Object-oriented C# console application for managing smart city urban mobility, fleet operations, and traffic simulation.

`C# 13` · `.NET 10` · `Layered Architecture` · `OOP & Polymorphism` · `LINQ` · `System.Text.Json` · `Haversine`

* **Layered Architecture**: Strict three-tier separation between domain models, business services, and presentation UI.
* **Advanced OOP Modeling**: Class hierarchy utilizing abstract base classes and multiple interface inheritance (thermal, electric, hybrid vehicles).
* **Haversine Distance**: Realistic geographic distance calculation between urban Points of Interest.
* **Traffic Simulation**: Engine modeling variable road traffic states and simulating commute durations.
* **LINQ Queries**: Advanced in-memory data filtering, multi-criteria search, and sorting services.
* **Data Persistence**: Structured JSON save and load capabilities with `System.Text.Json` and robust input validation.
